    How to Install

    Get Started in Minutes

    Follow these simple steps to install the DungeonSelects modpack and begin your adventure.

    1. 1

      Download the Mod

      Download the DungeonSelects .jar file from the download section.

      For Minecraft 1.21.11 with Fabric

    2. 2

      Install Fabric

      Run the Fabric Installer and select Minecraft 1.21.11.

      Make sure to select the correct Minecraft version

    3. 3

      Install the Mod

      Place the downloaded DungeonSelects .jar file in your mods folder.

      Or press Win+R and type %appdata%\.minecraft\mods

    4. 4

      Launch Minecraft

      Open the Minecraft Launcher, select the Fabric profile, and click Play!

      Make sure you have enough RAM allocated (4GB+ recommended)

    Frequently Asked Questions

    Common Questions

    Find answers to the most common questions about the DungeonSelects modpack.

    Which Minecraft version is compatible?

    DungeonSelects is compatible with Minecraft 1.21.11 using the Fabric mod loader.

    Is the modpack free?

    Yes! DungeonSelects is free to download and play. Download the .jar file, install Fabric, and place the mod in your Minecraft mods folder.

    Can I use it with other mods?

    DungeonSelects is designed to be compatible with most Fabric mods. However, some mods that significantly alter world generation or combat systems may conflict. We recommend testing carefully before combining with other mods.

    Are dungeons always different?

    Yes! All dungeons are procedurally generated, meaning each one has a unique layout, enemy placement, traps, and loot. No two dungeons are alike — you'll never explore the same dungeon twice.

    How do I report bugs or suggest features?

    Use our support channels to report bugs or suggest features. We read all feedback and strive to improve with every update.

    Does it work on multiplayer servers?

    Yes! DungeonSelects supports multiplayer. Both the server and all clients need to have the mod installed. The dungeon generation is synchronized between players, so you can explore and fight together in real-time.
